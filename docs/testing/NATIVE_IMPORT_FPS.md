## Practical limits

Pending cards cannot be dragged or placed. Native imports admit one local batch at a time, up to32 files, while committed clips remain editable; service clients share two preparation permits and16 active jobs. If a concurrent edit advances the revision, preparation can finish into cache but publication fails explicitly; Retry uses the latest observed revision. Cancellation is preparation-only and cannot undo an irrevocable commit. Ephemeral jobs/cache are not restart-resumable. Existing source/timestamp output limits remain; large footage may take longer or fail an explicit bound.

Matching is exact CFR and first moving video only, excluding PNG and existing independent-audio placements. Native manual selection lists23.976/24/25/29.97/30/50/59.94/60, while CLI supports valid exact rational rates. The rate stays locked while clips exist. Mixed-source-FPS clip composition and motion interpolation remain unsupported; export cadence conversion does not create new motion detail. Manual file-picker/drag/cancel interactions, high-DPI, unusual storage/codecs, physical devices and speaker/display A/V timing still need separate acceptance. No mock placements or generated media were added to the owner's project.
