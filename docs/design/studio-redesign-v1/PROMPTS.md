## A — Focus

Use case: ui-mockup. Create a polished, realistic high-fidelity design mockup of Lumeryn, a native Windows video-editing application for beginners and professional humans working alongside external coding agents. Single entire desktop application screen, straight-on, 1600x1000 logical viewport, landscape 16:10. No laptop, perspective, browser chrome, desktop wallpaper or marketing website. Crisp readable typography, convincing native controls, 8pt spacing grid, ample whitespace, accessible high contrast, compact clean vector icons, precise layout. Minimal elegant dark cinematic surfaces, restrained materials, no neon glow, glassmorphism or exaggerated shadows. This is a design concept, not a screenshot of working features.
Same sample project in every design: project name "Neural networks", a 60-second educational explainer. Preview displays a tasteful original motion-graphic frame on deep blue-black: three tidy columns of softly luminous mint and blue circular nodes connected by thin lines, caption "From inputs to answers", small labels "Input", "Hidden layers", "Output". The diagram should be clear and editorial, not a rainbow calibration pattern. Current playback position "00:24 / 01:00". Use five comparable segments named "Opening", "Inputs", "Hidden layers", "Output", "Recap". Common user actions accessible: import media, watch/play/pause/scrub, select/trim a clip, review recent edits, export. No embedded AI chat, prompt textbox, agent mascot, fake AI generation button, code, raw JSON, UUIDs, filesystem paths, hardware diagnostics or developer disclaimers on the main screen. Technical details would be an optional advanced drawer. Essential text must be readable and spelled accurately. Brand "LUMERYN". Include only plausible concise UI copy, avoid hundreds of tiny labels.
Direction A — FOCUS. Audience: first-time users who want to watch and make a few adjustments. Composition: exceptionally spacious preview-led screen. Top slim 64px header with LUMERYN at left, project breadcrumb in center-left, understated "Saved" indicator, quiet "Review changes" button and single mint "Export" button at right. A 64px left icon rail with understandable captions "Media", "Edit", "History", "Settings"; the content drawer is closed. Main video preview centered with generous surrounding margins, about 75% width and 55% screen height. No right inspector visible by default. Under preview a large simple transport bar: backward, circular mint play control, forward, elapsed/total time, quiet audio-volume icon. Bottom 190px simplified horizontal clip sequence with five visual cards and durations, mint playhead, clean second ruler and one selected card "Hidden layers"; a small "Open detailed timeline" affordance at far right. One contextual floating "Trim clip" button near selected clip, not a permanent properties wall. Premium charcoal #111317 / #1B1E24, restrained seafoam accent #A6E3CD, warm-white headings, humane 15–16px type. Let empty space and the video lead. This must look like an approachable creative tool, not a dashboard. Small unobtrusive label "A · Focus" in the top title area.
