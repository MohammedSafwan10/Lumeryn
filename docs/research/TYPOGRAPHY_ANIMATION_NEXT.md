# Editable typography, vectors, animation and templates: next slices

Research date: 2026-10-10. Status: researched implementation plan; no typography dependency, scene renderer, benchmark or new editing command has been implemented by this document. It extends the provisional direction in [ADR0005](../adr/0005-typography-audio.md), the editable scene contract in [ADR0009](../adr/0009-semantic-scenes-explainers.md), and roadmap C1–C6. Native egui/eframe remains Studio; references to Svelte controls in older research are superseded.

## Current boundary and recommendation

The actual `lumeryn-core/src/model.rs` graph is schema2 with one video track, independent audio and source-referenced frame ranges. `render.rs` implements a narrow supported graph, not a general scene compositor. The audited Inter Studio font changes application labels; it does not implement exported titles. Images currently import without timeline image holds. Composition and explicit migration must land before titles can be called an end-to-end feature.

Prefer **one headless Rust scene evaluator, one creative text layout engine, and one tested raster path for both preview and export**. Keep egui as editing chrome. Prefer Parley for the first selection experiment; compare cosmic-text on the same corpus and choose the smaller reliable implementation. Prefer a validated Vello CPU subset as reference/fallback; introduce Vello GPU only after Windows compatibility and useful measured acceleration. Use resvg for static SVG graphics at a declared fidelity boundary. This is a recommendation from API fit, not proof that these libraries are fastest on Lumeryn's workload.

## Minimal authoritative model

Extend the versioned graph deliberately; do not attach ad hoc JSON effects to clips. Start with editable text, rectangle, ellipse and connector/path nodes, grouping, fill/stroke, affine transform, opacity and rational spans. Image/video layers and gaps are shared composition prerequisites, not an independent title subsystem. Every object has a stable ID and deterministic z-order. References resolve through verified asset IDs. Reject unknown properties, duplicate IDs, cyclic parenting, invalid ranges, nonfinite numbers, overflowing dimensions and unsupported operations transactionally.

Use integer timeline frames and exact rational evaluation time; export FPS maps into that time without altering the project rate. Define half-open spans, local scene time and exact endpoint rules. Persist constrained property-specific keyframes, initially translation/scale/rotation/opacity, with Hold, Linear and one documented easing family. Resolve duplicate-time policy explicitly. Evaluate solely from time and project state, including backward seeks and exports; never accumulate animation from UI deltas. Rotations need an explicit shortest-path versus unwrapped-angle policy. Text edits relayout; ordinary translation/opacity animation reuses layout.

Logical scene coordinates are project-canvas pixels. Render requested UHD/portrait dimensions directly from the scene specification, not an upscaled preview. Layout width, font size and stroke geometry scale consistently; Studio DPI affects controls only. Do not let a lower-resolution preview choose different wrapping. Declare aspect-adaptation constraints/safe areas instead of guessing placements when changing ratios.

Font references contain content hash, face index, variation coordinates, shaping features and language/direction. Save the resolved fallback map. Missing faces/glyphs produce actionable warnings or errors before export; never silently substitute a machine font that changes line breaks. Start with existing audited Inter bytes plus specifically reviewed fallback families for the tested language corpus. Do not promise universal Unicode or colour emoji. Bundled font changes and subsetting must retain OFL notices and observe reserved names. [Official OFL terms](https://openfontlicense.org/open-font-license-official-text/) permit software bundling under their conditions and do not license the resulting video under OFL. Installed proprietary fonts are not redistribution assets.

Specify SDR colour space, alpha representation and blend semantics at adapter boundaries. Premultiplied raster RGBA must not be treated as straight alpha. Convert explicitly at a straight-alpha FFmpeg adapter boundary, define alpha-zero RGB and never gamma-transform alpha; all backends must reproduce the stored composition policy. Choose/test the common compositing convention before wider colour/effect work; encode conversion must handle ranges/transfer correctly. RGB/alpha goldens detect dark fringes and wrong blending. Neither RGBA8 nor an f32 intermediate proves HDR support.

## Smooth native interaction and complete agent contracts

The existing left Text/Library drawer should expose a compact searchable grid of original style previews, plus Plain text and simple shapes. Selecting a style inserts real editable nodes through the shared service. The right contextual drawer edits text, font, size, alignment, fill, position and animation; advanced controls collapse. Timeline scene/text lanes expose duration and keys. Canvas selection handles show real bounds with hit testing in the same logical coordinates.

During dragging or slider changes use a transient draft over a captured revision. Throttle background previews, cancel stale generations and commit one coalesced undo step on acceptance. Pointer cancellation discards the draft. External changes yield an explicit conflict/reload decision; draft appearance never masquerades as a persisted revision. Playback/scene rasterization must not block the UI thread. Test keyboard editing, focus, IME, long labels, both drawers and compact widths instead of treating screenshots as interaction acceptance.

The names below are proposed contract groups, not existing CLI commands: scene/node create/inspect/set/remove, text layout inspect, keyframes list/set/remove, template list/inspect/instantiate, frame/contact-sheet render and scene check. Publish only implemented fields through capabilities and JSON schemas, including renderer/font requirements and supported interpolation. Existing explicit project selection, expected revision, idempotency, batch dry-run and atomic validation apply. Both clients must use the same expansion and layout service; no hidden Studio-only effect. Diagnostics report object ID, range, missing asset or unsupported property without dumping confidential text by default.

Templates are versioned declarative parameter schemas expanded into ordinary nodes and keyframes with returned stable IDs. Preserve preset version and provenance; initial templates can simply instantiate and then allow normal manual edits. Regeneration/override reconciliation can follow later, rather than requiring a template framework before useful titles ship. Reject project-supplied Rust/WGSL/Python/JavaScript, arbitrary expressions, external URLs and shell commands. Bound nesting, text/path lengths, glyph/node/keyframe counts, image dimensions and resource/time budgets. SVG importing must disable external resource resolution/network access, confine approved local references, cap embedded/decompressed content and report unsupported features. Animated SVG/Lottie is not implied by a static SVG import.

Do not postpone every manual/device check to the final slice. Measure the actual small scene and representative busy scene separately: static text, animation without relayout, moving vectors, many glyphs and transparent overlap. Targets such as fitting within a60FPS frame budget are unachieved goals; decode, scheduling, raster, transfers and UI each require their own measurements. GPU acceleration is optional if CPU meets the tested slice's budget.

Before claiming parity, compare headless reference frames against native preview at the same revision/time and compare lossless output pixels. Encoded H.264/H.265 require justified compression-aware image tolerances plus decoded resolution/FPS/frame-count/duration checks and existing sample/flash A/V fixtures. Golden acceptance records font hashes, renderer/settings and colour conversion, not just a screenshot name. Standard locked fmt/strict Clippy/tests/media/deny and real native gates remain mandatory for later code changes.

## Unresolved choices that require experiments

Parley versus cosmic-text quality/integration cost; exact released Vello GPU compatibility with wgpu30.0.1; CPU render and GPU transfer cost at UHD; safe renderer/filter subset; deterministic multilingual fallback packs; portable font packaging rights; colour-emoji support; cache budget and renderer-specific pixel tolerance. No current benchmark proves a winner. These do not block a useful static-title spike and should not justify adding several competing stacks or replacing the authoritative Rust graph.
