# ADR 0019: Consistent Inter UI and task-focused native panels

Date: 2026-10-10. Status: implemented; executed acceptance is in testing/STUDIO_POLISH.md. This changes native presentation and defaults, not the authoritative renderer or project semantics.

The owner rejected cluttered Export and Project panels and asked for researched, consistent editor typography. Use the existing audited Inter Regular variable face, unmodified, as the first proportional egui font. Register it once during initialization, retain default glyph fallbacks and technical monospace text, and keep the current restrained22/15/12pt scale. Its default weight400 and optical size14 were inspected from the actual font. Inter is designed for interface text and its SIL Open Font License permits embedding under its conditions; include the existing exact notice and expose it in native diagnostics. [Inter](https://rsms.me/inter/), [release4.1](https://github.com/rsms/inter/releases/tag/v4.1), [egui0.36.2 font definitions](https://docs.rs/egui/0.36.2/egui/struct.FontDefinitions.html).

Use no additional font dependency or download. The876,576-byte face is already in the reviewed library. Keep exact hashes/notices, optional glyph fallbacks and documented script limits. This is a measured-context design selection, not a universal best-font claim. Segoe UI would depend on Windows installation and does not grant arbitrary font redistribution rights; Noto Sans and Source Sans3 remain audited alternatives if native evidence warrants replacing Inter. Full official references and exact assets are in research/STUDIO_TYPOGRAPHY.md.

Group Export into resolution choices, frame rate/codec/quality, a collapsed encoder/bitrate section and a fixed filename/destination/action area. Scroll only settings at compact heights; output controls must remain reachable. Show a short destination label with the full path on hover. Normal Studio defaults to1080p/H.264/automatic hardware selection with existing safe software fallback; CLI and ordinary synthetic smoke retain compatible baseline defaults. Unsupported installed encoders still fail explicitly. No paywall, account, cloud upload or watermark is added.

Project drawer shows name, canvas aspect, pixel size, readable frame rate and duration. Put paths/revisions in File details and direct-path import/open tools in the advanced workspace; existing native pickers and header/media actions remain available. The same Rust commands still own canvas/export/media editing.

Inter UI labels are not editable creative titles and do not establish typography preview/export parity. Native scene fonts/layout/glyph identities require the existing shared creative pipeline and specific export tests. Actual script coverage, highDPI/physical input, glyph atlas memory and controlled before/after cold-start comparisons remain separate acceptance. Debug update timings are not display FPS. No unsafe code, backend replacement, source mutation, model installation or proprietary-status change is introduced.
